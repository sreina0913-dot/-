# ENGLISH QUEST

英文を一文ずつ読み、日本語訳をAIに採点してもらう英語長文読解ゲームの試作版です。

## 機能
- 日本語訳を入力してAIに採点してもらう
- 攻略ポイントごとに0〜20点で評価
- 90点以上で攻撃成功、100点で完全クリア
- 理解不足の場合はヒントを表示

## 起動方法
Node.js 18以上が必要です。

1. `npm install`
2. `.env.example` を `.env` にコピー
3. `.env` の `OPENAI_API_KEY` に自分のAPIキーを設定
4. `npm start`
5. ブラウザで http://localhost:3000 を開く

APIキーはブラウザ側のコードやGitHubに書かず、サーバー側の環境変数に設定してください。

## 教材データについて
このリポジトリには動作確認用のオリジナル英文だけを収録しています。市販教材『速読英単語 必修編 第8版』の本文や訳文を公開リポジトリに転載しないでください。教材データを追加する場合は利用条件を確認し、公開しない方法で管理してください。

AI採点は常に完全とは限りません。実際の学習に使う前に複数の訳で動作を確認し、基準を調整してください。
